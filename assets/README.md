# Recursos del proyecto

- `css/`: hojas de estilo de la interfaz.
- `js/`: lógica del juego, escenario Three.js, controles WebXR y generación de audio.

En esta versión, el escenario y las texturas pixel-art se generan mediante código y la música/efectos se sintetizan con Web Audio API. Por eso no se incluyen carpetas vacías de modelos, imágenes ni archivos MP3. Cuando se incorpore un recurso externo, debe añadirse aquí en una subcarpeta específica, con nombre descriptivo, formato comprimido y referencia de licencia.
