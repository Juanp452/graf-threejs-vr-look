# Plan de evidencias para la práctica 3.7

Guardar capturas en una carpeta local `evidencias/` (no incluir videos pesados en el repositorio salvo que el docente lo solicite).

| Clave | Captura / evidencia | Qué debe demostrar |
|---|---|---|
| E01 | Introducción cinematográfica | Secuencia inicial VHS y opción para omitirla |
| E02 | Menú principal | Título, dificultad, opciones de audio y calidad |
| E03 | Escenario 3D en PC | Primera persona, bosque, HUD y linterna |
| E04 | Archivo de páginas | Página recién recogida y progreso del archivo |
| E05 | Eventos de terror | Primera aparición, interferencia o evento ambiental |
| E06 | Expediente final | Pantalla de victoria o derrota con estadísticas |
| E07 | IWE en escritorio | Sesión WebXR emulada, visor y mandos simulados |
| E08 | Controles emulados | Evidencia de movimiento, trigger, grip y botones |
| E09 | Meta Quest 3S físico | Foto/captura del juego dentro del visor (solo si se prueba físicamente) |
| E10 | GitHub Pages | URL pública abierta y funcionamiento en HTTPS |
| E11 | GitHub Actions | Workflow terminado correctamente |

Para la evidencia IWE, anotar que es una simulación. E09 debe identificarse como prueba física únicamente después de utilizar el visor real.
